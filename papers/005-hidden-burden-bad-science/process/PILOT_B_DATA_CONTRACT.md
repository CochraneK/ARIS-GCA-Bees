# PILOT B DATA CONTRACT — ARIS4C005

## Principle

Pilot B uses detector-enriched sampling for efficiency **without pretending it is a simple random sample**.

Every sampled work must retain enough information to reconstruct its selection probability.

---

## Input feature-frame schema

Required identifiers:

| column | meaning |
|---|---|
| `paper_id` | stable project-local ID |
| `doi` | normalized DOI when available |
| `openalex_id` | OpenAlex work ID when available |
| `publication_year` | publication year |
| `field` | frozen broad field |
| `work_type` | article/review |
| `fulltext_access` | access class, not a quality signal |

Detector columns use `1` = positive, `0` = negative, blank/NA = not applicable or missing, with an accompanying applicability/missingness field where needed.

Initial detector families may include formal retraction, expression of concern, narrow E1-S reasons, high-specificity paper-mill signals, image anomaly, text pattern, statistical inconsistency, duplicate data/text, and public post-publication concern.

A detector may not enter the feature frame until its provenance, applicability population, and validation status are documented.

---

## Sampling output fields

Generated by `code/pilot_b_sample.py`:

- `aris_pilot_b_stratum`
- `aris_selected_via`
- `aris_pi_random`
- `aris_pi_enrich`
- `aris_inclusion_probability`
- `aris_design_weight`
- `aris_sampling_seed`

Sampling is independent Bernoulli/Poisson in two components. For paper i:

`pi_i = 1 - (1 - p_random) * (1 - p_enrich,stratum)`

CLI sample-size targets are **expected** sample sizes.

---

## Adjudication fields

Required minimum:

- `paper_id`
- `reviewer_id`
- `review_round`
- `scientific_state`
- `materiality`
- `misconduct_evidence`
- `publication_process_state`
- `review_confidence`
- `fulltext_seen`
- `notice_seen`
- `formal_finding_seen`
- `evidence_locator`
- `adjudication_note`
- sampling fields copied unchanged from the sample file

Do not overwrite the original detector features after human review.

---

## Binary calibration reference

For `calibrate_detectors.py`:

Positive: `SEVERE_SUPPORTED`.

Negative: `HONEST_MAJOR_ERROR`, `MINOR_OR_IMMATERIAL`, `NO_MATERIAL_PROBLEM_FOUND`.

Excluded from binary sensitivity/specificity denominators but retained in reports: `SERIOUS_UNRESOLVED`, `INDETERMINATE`.

---

## Weighting

Primary design weight:

`w_i = 1 / pi_i`

Calibration output must include Kish effective sample size because heavy enrichment can make raw sample size misleading.

Later analyses may add nonresponse/adjudication-completion weights, post-stratification, and field/year calibration weights. Those must be separate columns. Never silently replace the original sampling weight.

---

## Provenance requirements

For each detector release/store:

- tool/model/version;
- run date;
- exact input universe;
- applicability rule;
- threshold;
- missingness rule;
- training-data overlap with Retraction Watch/manual labels;
- known demographic/geographic/language leakage risks;
- license/redistribution constraints.

This is particularly important for paper-mill/text detectors because training on already retracted cases can reproduce the biases of the detection system.

---

## Public repository policy

Allowed: schemas, code, aggregate calibration metrics, public identifiers already present in source databases, and public formal correction metadata.

Do not publish restricted full text, private allegations, an unretracted-author fraud-score list, or model-generated accusations.

A public row-level adjudication release, if any, must be restricted to evidence already public and phrased as article-state coding, not person-level guilt.

---

## Gate to Pilot C

Pilot C can consume a Pilot B dataset only when:

1. all selected rows have valid `0 < pi <= 1`;
2. weights reproduce known frame totals within Monte Carlo/design tolerance;
3. duplicate work IDs are resolved;
4. detector missingness is explicit;
5. adjudication label vocabulary validates;
6. random-component and enriched-component composition is reported separately;
7. at least one detector has estimable calibration metrics;
8. unresolved cases are not silently recoded as negative.
