# AI CALIBRATION ANCHOR PROTOCOL — ARIS4C005\n\n## Purpose\n\nCalibrate AI adjudicators as fallible measurement instruments for the article-level severe scientific-state target.\n\nCalibration is not the same as inter-model agreement. AI_A and AI_B can agree and still be jointly wrong.\n\n---\n\n## Calibration target\n\nPrimary binary target:\n\n- positive: `SEVERE_SUPPORTED`\n- non-positive: all states not meeting the severe-supported definition\n\n`SERIOUS_UNRESOLVED` and `INDETERMINATE` are not forced into either class when building reference truth.\n\n---\n\n## Anchor families\n\n### P+ — high-confidence positive anchors\n\nPreferred evidence:\n\n- formal institutional finding tied to the work;\n- publisher notice explicitly documenting fabricated/falsified/invalid material scientific data or results;\n- independently reproducible forensic evidence that materially invalidates a principal claim.\n\nRetraction status alone is insufficient.\n\n### N+ — high-confidence non-severe anchors\n\nPreferred evidence:\n\n- explicit publisher/institutional evidence that a known issue is administrative, duplicate-publication, authorship, plagiarism-only, or otherwise scientifically immaterial **and** the primary scientific claim is documented as unaffected;\n- independently verified cases in which the relevant main claim remains scientifically usable despite the publication-process issue.\n\nAbsence of retraction, correction, concern, or detector signal is **not** a high-confidence negative anchor.\n\n### U — unresolved anchors\n\nAnything with ambiguous materiality, incomplete evidence, allegation-only status, inaccessible evidence, or conflicting notices remains unresolved and is excluded from accuracy estimation.\n\n---\n\n## Blinding\n\nAI adjudicators must not receive:\n\n- the anchor truth label;\n- whether the case was sampled as positive/negative;\n- detector/enrichment stratum;\n- another adjudicator's answer.\n\nReference truth is joined only after the AI output is frozen.\n\n---\n\n## Spectrum coverage\n\nCalibration anchors should span where feasible:\n\n- fields/domains;\n- publication years;\n- article/review types;\n- DOI/no-DOI cases;\n- full-text access states;\n- obvious and subtle severe failures;\n- severe failures with and without formal retraction;\n- scientifically immaterial publication-process failures.\n\nA spectacular-case-only positive set inflates apparent sensitivity. A trivially clean negative set inflates apparent specificity.\n\n---\n\n## Anchor quality\n\nEvery anchor receives one level:\n\n- `A`: direct formal/primary evidence with clear materiality;\n- `B`: strong multi-source evidence with minor residual ambiguity;\n- `C`: plausible but not strong enough for primary calibration.\n\nPrimary Se/Sp calibration uses A anchors; A+B is sensitivity analysis; C remains descriptive.\n\n---\n\n## Rare-event specificity constraint\n\nFor rare article-level severe failure, specificity dominates positive predictive value.\n\nEven if no false positives are observed, a small negative-anchor set cannot demonstrate extremely low false-positive rates.\n\nFor n independent negative anchors with zero false positives, the exact one-sided upper confidence bound on FPR is:\n\n`FPR_upper = 1 - alpha^(1/n)`\n\nwhere `alpha = 1 - confidence`.\n\nAt 95% confidence, roughly:\n\n- proving FPR < 1% with zero errors requires ~299 negatives;\n- FPR < 0.5% requires ~598;\n- FPR < 0.1% requires ~2,995;\n- FPR < 0.05% requires ~5,990;\n- FPR < 0.01% requires ~29,956.\n\nTherefore modest anchor panels cannot justify treating specificity as 99.9–99.99% known. Final inference must combine empirical anchors with explicit sensitivity/partial-identification analysis.\n\n---\n\n## Dependence and transportability\n\nAnchor observations are not independent when they share:\n\n- the same retraction notice template;\n- the same paper-mill family;\n- the same institution/investigation;\n- near-duplicate papers;\n- the same evidence packet.\n\nClustered anchors reduce effective calibration information.\n\nAccuracy can also vary by field, access, year, failure type, and evidence availability. Report stratified performance where sample size permits.\n\n---\n\n## Required outputs\n\nAt minimum:\n\n- TP / FN / TN / FP;\n- sensitivity and specificity with uncertainty;\n- abstention / unresolved rate;\n- performance by anchor quality;\n- performance by evidence-access state;\n- correlated-error sensitivity between AI_A and AI_B;\n- calibration sample composition and exclusions.\n\nDo not report a single accuracy percentage as the calibration result.\n\n---\n\n## Go / no-go\n\nGlobal latent prevalence remains blocked if:\n\n- negative anchors are too weak to inform specificity;\n- positive anchors are too narrow to inform sensitivity across failure types;\n- AI abstention is highly differential by likely severity;\n- conclusions change materially under plausible specificity/shared-error scenarios;\n- anchor truth was influenced by the AI outputs being evaluated.\n
