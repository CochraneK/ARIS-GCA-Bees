# ARIS4C009 · Research plan

## Working title

**The Fidelity Frontier in Computational Psychiatry: Decomposing Acquisition and Encoding Loss in Psychopathology**

## 1. Core problem

Psychiatric research repeatedly transforms lived experience into scientific representations, but at least two different processes are often conflated:

[
H ightarrow A_m ightarrow X^{(m)} ightarrow E_k ightarrow Z^{(m,k)}
]

where:

- (H) = lived state, not directly observable;
- (A_m) = acquisition/elicitation method;
- (X^{(m)}) = evidence generated by method (m);
- (E_k) = encoding/representation method;
- (Z^{(m,k)}) = resulting coded/quantitative representation.

A phenomenological interview and a self-report questionnaire can differ because they **elicit different evidence**. A transcript and a symptom-code projection can differ because the **same evidence was encoded differently**.

ARIS4C009 studies these separately.

## 2. Primary contribution

The project proposes a measurement architecture with five distinct evaluation families:

1. **source-grounded fidelity**;
2. **reliability**;
3. **intended-use validity**;
4. **predictive/intervention utility**;
5. **burden, privacy and representation rate**.

No single dimension defines the "best" psychiatric representation.

The target is a **use-conditioned Pareto frontier**.

## 3. Paper sequence

### 009A1 · Same-source encoding benchmark

Primary first executable paper.

Hold a rich source record fixed and generate multiple representations:

- **R0:** rich source record;
- **R1:** structured phenomenological episode graph;
- **R2:** specialist phenomenological coding;
- **R3P:** questionnaire-format projection generated from the same source;
- **R4P:** conventional symptom-code projection generated from the same source;
- **R5:** low-dimensional quantitative representation;
- **R6 exploratory:** frozen LLM-assisted representation.

R3P is **not** participant self-report.  
R4P is **not** an independently administered clinical interview.

009A1 isolates encoding divergence conditional on a fixed acquisition source.

### 009A2 · Acquisition-method benchmark

Purpose-collected multimethod study.

#### A2a matched-content experiment

Assess the same focal episode with:

- M1 self-administered fixed response;
- M2 fully structured interviewer;
- M3 phenomenological semi-structured interview.

Randomize one of the six method orders.

Use:

- randomized first-method estimand for the cleanest method effect;
- full crossover model for within-person divergence and order/carryover.

#### A2b native-instrument comparison

Compare actual tools such as:

- phenomenological interviews;
- participant-completed self-report;
- conventional clinical assessment;
- EMA/ESM.

This estimates real-world method divergence but does not pretend construct coverage and time windows are identical.

### 009B · Cross-level neurophenomenology

Only after measurement calibration.

Add behavior, computational tasks, EEG/ERP and optionally fMRI.

Question:

> Does phenomenological structure explain independent variance beyond conventional clinical dimensions, and do competing computational mechanisms make discriminating predictions?

### 009C · Longitudinal person-specific dynamics

Combine:

- periodic deep phenomenological assessment;
- EMA;
- contextual anchors;
- treatment/life events;
- optional passive sensing.

Compare pooled, hierarchical and person-specific state-space models using forward validation.

### 009D · Perturbation/intervention validation

Test whether inferred states/mechanisms predict changes under treatment or controlled ecological perturbation.

## 4. 009A1 research questions

### RQ1 · Encoding loss

How much source-grounded information is retained by each same-source representation?

### RQ2 · Domain fragility

Which experiential domains are especially vulnerable to aggressive encoding?

Candidate domains:

- ownership/mineness;
- agency;
- self-other/world boundary;
- body;
- time;
- space;
- salience/familiarity;
- affect;
- language;
- meaning;
- certainty;
- social relation.

### RQ3 · Rate/burden trade-off

Does a representation remain favorable after matching description rate and encoding burden?

### RQ4 · Fidelity versus intended use

Can a lower-fidelity representation outperform a richer one for a specific screening/prediction task?

A "yes" is compatible with the framework.

## 5. 009A1 source material

Preferred initial domain: schizophrenia spectrum / early psychosis because the phenomenological measurement literature is relatively mature.

For each focal episode preserve, subject to ethics:

- participant wording;
- relevant interviewer prompts;
- immediate context;
- temporal qualifiers;
- uncertainty;
- literal/metaphoric status when clarified;
- attribution;
- relevant medication/sleep/substance context when consented;
- provenance pointers.

The source record is a **fixed evidential reference**, not ground truth lived experience.

## 6. Independent reconstruction benchmark

Three-panel design:

- **Panel A:** constructs questions using source only;
- **Panel B:** adjudicates answerability/reference answers using source only;
- **Panel C:** sees one representation and answers frozen questions.

No representation writes its own exam.

Primary fidelity families:

- semantic;
- relational;
- contextual;
- temporal;
- participant-endorsed where feasible.

## 7. Fair comparison

### Raw comparison

Report observed fidelity and burden.

### Equal-rate comparison

Compare representations at overlapping information/description rates.

Candidate rate measures:

- tokens/characters;
- structured-field count;
- dimensionality;
- defensible description-length measures.

### Encoding-burden comparison

Because A1 acquisition source is fixed, compare representation-generation burden separately:

- coder minutes;
- expert minutes;
- compute;
- storage/complexity.

For real-world deployment, also report total burden:

[
C_{total}=C_{acquisition}+C_{encoding}
]

but do not use total burden to imply that A1 experimentally manipulated acquisition.

## 8. Intended-use validity

For use (u):

[
V_{use}(Z,u), quad U(Z,u)
]

Potential uses:

- rich description;
- screening;
- diagnosis/classification;
- mechanism;
- prediction;
- monitoring;
- intervention selection.

Low narrative fidelity does not automatically invalidate a tool for a narrow intended use.

## 9. 009A2 physical/context constraint

For independently observable context define optional:

[
W_t=(time,location,activity,social context,sleep,medication timing,physiology,ldots)
]

Use (W_t) only to constrain physical/context claims.

Do not use it to decide:

- felt ownership;
- experienced agency;
- salience;
- meaning;
- reality quality;
- self-world boundary.

### Multitrait–multimethod extension

Estimate:

- domain/trait variance;
- method variance;
- person variance;
- method × domain interactions.

Do not force one latent "true psychopathology" if the data do not support it.

## 11. Power/precision

Do not power on patient count alone.

Information depends on:

- participants;
- episodes/person;
- nonredundant adjudicable queries/episode;
- evaluator variance;
- source ambiguity;
- missingness;
- domain × representation interaction.

Use pilot-calibrated simulation.

## 12. Reliability gates

Separate from fidelity.

Pilot candidate gates:

- Gwet AC1/AC2 for categorical adjudication;
- ICC for continuous/ordinal components;
- relation-level rater F1;
- calibration for probabilistic judgments.

Thresholds must be frozen after pilot and before confirmatory scoring.

## 13. Mechanistic model competition

Active inference is a candidate, not the ontology.

Candidate families:

- active inference / predictive processing;
- reinforcement learning;
- sequential sampling;
- dynamical systems;
- symptom/experience networks;
- control theory;
- information-theoretic models.

Strong mechanistic claims require:

- parameter recovery;
- competing-model comparison;
- discriminating predictions;
- out-of-sample validation;
- preferably perturbation/intervention evidence.

## 14. Longitudinal extension

For person (i):

[
s_{i,t+1}=f_i(s_{it},e_{it},u_{it})+epsilon_{it}
]

[
y_{it}=g_i(s_{it})+eta_{it}
]

Compare:

- persistence/person-mean baselines;
- VAR;
- Kalman/switching SSM;
- hierarchical Bayesian SSM;
- PLRNN/nonlinear SSM;
- Gaussian-process SSM;
- sequence models as predictive comparators.

Use forward-only validation.

## 15. Cross-cultural requirement

Preserve:

- original language;
- translated text;
- translation provenance;
- translation uncertainty;
- culture-specific interpretation notes.

Original-language analysis is preferred where feasible.

## 16. Ethics

Rich psychiatric evidence can be highly identifying.

Requirements:

- data minimization;
- de-identification;
- tiered access;
- consent appropriate to source;
- separate permission for passive sensing;
- stopping/distress procedures;
- no covert monitoring;
- no autonomous clinical decision from experimental scores;
- privacy risk included in burden/cost.

## 17. Novelty boundary

The project does not claim to invent:

- computational phenomenology;
- phenomenological fidelity;
- narrative distortion;
- interview/self-report divergence;
- clinical summarization;
- computational psychiatry ecological validity;
- use-conditioned validity.

The candidate contribution is the integrated experimental architecture:

[
H ightarrow A_m ightarrow X^{(m)} ightarrow E_k ightarrow Z^{(m,k)}
]

plus independent reconstruction benchmarking and use-conditioned Pareto analysis.

See `GATE_A_NOVELTY_REVIEW_2026-09-19.md`.

## 18. Strong falsification

The program must tolerate the following outcomes:

- coarse representations preserve nearly all important same-source information;
- phenomenological probing adds only verbosity;
- acquisition method explains more divergence than encoding;
- evaluator expertise determines representation ranking;
- rate matching eliminates rich-representation advantages;
- compact representations dominate for specific use cases;
- person-specific dynamics add little beyond regularized population models.

## 19. Current execution order

1. obtain ethically usable pilot source episodes;
2. pilot source adjudication/query bank;
3. estimate redundancy/reliability/evaluator variance;
4. freeze 009A1 representation-generation rules;
5. rerun power/precision simulation with empirical variance components;
6. preregister and run 009A1;
7. only then commit resources to purpose-collected 009A2;
8. mechanistic/neural/longitudinal layers follow measurement validation.
