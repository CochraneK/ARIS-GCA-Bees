# Tier-1 recoverability v2 · Pilot 8

## Why a v2 diagnostic was required

The legacy simulation used unequal and overlapping candidate feature sets. In complete 79-taxon simulations, the flexible interaction candidate frequently captured outcomes generated by weakest-link or threshold mechanisms. That means the legacy exact-label recovery rate measured both panel quality **and** avoidable model-definition overlap.

The legacy files remain in the repository as an audit trail.

## Architecture-balanced primary gate

V2 uses three pre-specified one-dimensional static signatures:
- additive = mean module capacity;
- weakest-link = minimum module capacity;
- threshold = a fixed nonlinear transition based on how many modules exceed a candidate threshold, with a small mean-capacity term.

Every architecture is fitted with the same intercept + slope complexity.

The project does **not** delete interaction/feedback hypotheses. It removes the invalid practice of representing feedback as an unconstrained static polynomial in the recoverability gate. Dynamic feedback must instead be tested using explicit temporal/network models.

## Results

| Scenario | Coverage | Additive | Weakest | Threshold |
|---|---:|---:|---:|---:|
| Pilot-7 current 29 | 45.9% | 0.642 | 0.478 | 0.386 |
| Tier-1 empirical 79 | 36.0% | 0.768 | 0.414 | 0.448 |
| New 50 A–F completed only | 70.3% | 0.994 | 0.526 | 0.310 |
| All 79 A–F completed | 86.5% | 1.000 | 0.742 | 0.550 |
| Complete 79, random latent configurations | 100% | 1.000 | 0.850 | 0.748 |
| Complete 79, architecture-signature oracle | 100% | 1.000 | 1.000 | 0.915 |

500 repetitions are used for fixed-mask scenarios; the oracle upper bound uses 200 repetitions.

## G–J gap decomposition after A–F completion

Completing one additional block across all 79 changed threshold recovery approximately to:
- +G: 0.532;
- +H: 0.556;
- +I: 0.596;
- +J: 0.608.

Leave-one-G–J-block-at-empirical-coverage diagnostics:
- J empirical, G/H/I complete: threshold 0.694;
- I empirical, G/H/J complete: 0.722;
- H empirical, G/I/J complete: 0.686;
- G empirical, H/I/J complete: 0.746;
- all G–J complete: 0.748.

Therefore G is already dense enough to contribute little additional recoverability in this toy diagnostic. H and J are more consequential remaining standardized-data gaps, with I intermediate.

## Interpretation

The result does **not** say that J or H are biologically more important causes of intelligence. It says that **their missingness currently limits our ability to tell candidate architectures apart**.

The result also does not prove that 79 is the final correct sample size. It shows:
- 79 is no longer obviously underpowered in principle;
- complete random configurations still leave threshold recovery below the configuration-diverse upper bound;
- deliberate dissociation/counterexample geometry remains valuable.

## Gate decision

The model-recoverability gate remains **BLOCKED**.

To unblock, the study must:
1. complete A–F deep coding across the Tier-1 expansion;
2. backfill A–F in the retained 29;
3. independently code O1–O7 outcomes;
4. improve H/J measurement where feasible;
5. quantify empirical architecture-signature geometry;
6. rerun recovery under observed measurement error/missingness;
7. keep dynamic feedback/network hypotheses in a separate temporally specified model family.

Only then can “necessary”, “sufficient”, “bottleneck” or “threshold” claims enter confirmatory analysis.
