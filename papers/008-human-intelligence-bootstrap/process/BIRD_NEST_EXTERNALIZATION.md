# Global bird nest-traits layer · ARIS4C008

**Source:** Sheard et al., *Nest traits for the world's birds*, Global Ecology and Biogeography.  
DOI: 10.1111/geb.13783  
Data archive: Zenodo 10.5281/zenodo.10009756.

## Coverage

The species-level Dataset S2 contains 11,120 rows in the retrieved archive and covers all **7 / 7** bird species in the current 008 panel.

The database metadata defines:
- `1` = yes;
- `0` = no;
- `u` = uncertain;
- `NA` = information not available.

These states are preserved.

## Externalization coding

A known nesting **location** is not enough to code persistent external construction. The S2 structure fields are used conservatively.

Current result:
- **Corvus corax:** positive — cup structure = 1;
- **Corvus moneduloides:** positive — cup structure = 1;
- five other panel birds: ambiguous from the species-level structural summary, because their relevant structure states are uncertain or unavailable.

This does not mean the five species build no structures. It means this particular standardized source does not justify a clean positive structural code under the project's rules.

## Why this matters for E

The database provides a route to compare persistent animal-built structures at scale rather than selecting only spectacular examples.

It also suggests an important future falsification design: once construction is coded across a broad bird panel, persistent environmental structures can be tested as an **enabling or amplifier** variable rather than assumed sufficient for open-ended culture.

The present seven-species extraction is only the first E-layer source; mammalian/invertebrate constructions and durable tool traditions need separate systematic sources.
