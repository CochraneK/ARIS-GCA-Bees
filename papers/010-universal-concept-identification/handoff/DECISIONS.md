# ARIS4C010 · Decision log

This file is append-oriented. Preserve superseded decisions when they explain why the project changed direction.

## 2026-09-19 · Continuity-standard bootstrap

**Decision:** Git is the cross-device / cross-account / cross-agent canonical continuity surface.

## 2026-09-19 · Do not build one perfect universal tree

**Decision:** use a typed multi-axis representation plus compositional operators.

**Why:** polysemy, negation, relations, modality, context, vagueness, empty/impossible descriptions and self-reference are cross-cutting.

## 2026-09-19 · Semantic Query Overhead is the core measurable object

**Decision:** compare semantically admissible query cost with unrestricted information-theoretic identification cost.

**Why:** generic information gain, Test Cover, GBS, REG and ontology-guided query learning are existing prior art.

## 2026-09-19 · P3 added between P2 and P6

**Decision:**
- P2 = YES/NO
- P3 = YES/NO/MAYBE
- P6 = YES/NO/BORDERLINE/UNKNOWN/UNDEFINED/BOTH

**Why:** 2025–2026 prior art already uses coarse non-binary answers. The defensible mechanism question is whether fine semantic failure-state distinctions add value **beyond a generic MAYBE**.

## 2026-09-19 · Human gate cannot be replaced by AI

**Decision:** LLM/synthetic/model oracle data may be separate baselines or dry-runs only; they cannot satisfy the Stage-A human calibration gate.

## 2026-09-19 · Current default is evidence collection, not ontology expansion

**Decision:** stop expanding ontology prose unless human calibration or new prior art forces redesign.

## 2026-09-19 · Ontology-guided active querying is a baseline

**Decision:** ICAART 2026 ontology-guided Bayesian active querying and ICML 2025 adaptive natural-language elicitation must be treated as close ancestors/baselines, not novelty.
