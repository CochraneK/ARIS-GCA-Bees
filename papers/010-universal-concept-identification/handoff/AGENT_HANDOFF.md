# ARIS4C010 · Agent takeover brief

## What this project is

**Beyond Twenty Questions: Semantic Limits and Query Complexity of Universal Concept Identification**

The canonical question is:

> **How much query complexity is added by semantic admissibility across heterogeneous and non-classical concept regimes, and where does exact identification become undefined or impossible?**

The project does **not** aim to discover one perfect taxonomy tree of everything. It studies identifiability relative to an explicit target universe, admissible query language, response protocol, context model and oracle.

## Critical 2026 novelty correction

Do **not** claim novelty for:

- generalized binary search / information gain;
- Test Cover / minimum separating features;
- ontology-guided active questioning;
- adaptive natural-language elicitation;
- coarse non-binary YES/NO/MAYBE responses;
- open-world active learning by itself.

Important closest neighbors include Wang et al. ICML 2025 adaptive elicitation and Agafonov et al. ICAART 2026 ontology-guided Bayesian active querying.

The surviving candidate wedge is:

> **semantic admissibility overhead and failure modes across heterogeneous concept regimes, with explicit fine-grained response semantics and open-world/pathological boundaries, measured against unrestricted identification.**

## Why P3 exists

The human design is now:

- **P2:** YES / NO
- **P3:** YES / NO / MAYBE
- **P6:** YES / NO / BORDERLINE / UNKNOWN / UNDEFINED / BOTH

Mechanism:

- P2→P3 = value of any coarse escape from binary forcing;
- **P3→P6 = key mechanism test**: value of distinguishing *why* binary judgment fails;
- P2→P6 = total protocol effect.

A complete balanced cycle contains **108 forms = 36 P2 + 36 P3 + 36 P6**, each with 84 unique formal trials + 8 retests.
