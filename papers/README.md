## Stable paper layout

Each promoted paper owns one stable folder containing paper.json plus code, data, manuscript and process records when applicable.

## Rules

1. One promoted paper, one numbered folder.
2. paper.json is the canonical portfolio metadata record.
3. Record the exact ARIS release and commit used.
4. Keep evidence, code, process and manuscript artifacts with the paper that generated them.
5. Synthetic outputs must be labeled and must not be presented as empirical observations.
6. Reconstructed papers may replace weak canonical claims when the replacement is explicit; Git history remains the archive.
7. docs/index.html is the public portfolio, not the canonical data source.
