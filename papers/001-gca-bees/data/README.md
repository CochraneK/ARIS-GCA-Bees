# Data

No empirical bee dataset is committed here yet.

The only current machine-readable result, model_recovery_synthetic.json, is generated from synthetic Gaussian latent-variable data for design diagnostics. It must never be merged with, plotted as, or described as an observation from bees.

Planned empirical inputs:

1. individual-level or reconstructable covariance data from Finke et al. (2023);
2. trial-level opt-out data following the Perry & Barron (2013) paradigm if available;
3. preferably a new same-individual multi-task battery with colony, order, motivation and attrition variables.

Raw-data provenance must be written here before any confirmatory result is promoted.
