# ADVERSARIAL AUDIT · ARIS4C001

## Legacy claims tested

### Claim: “precision distributions were empirically fitted”
**Verdict:** reject.  
The legacy code manually selected beta-distribution parameters and rescaled them. Literature-inspired ranges are not equivalent to fitting a generative distribution to empirical individual-level data.

### Claim: “a single precision parameter explains 83.5% of variance, validating the architecture”
**Verdict:** reject as circular validation.  
The simulated variables were constructed as functions of the same latent parameter. Large shared variance is therefore partly a design consequence and cannot independently validate the generator.

### Claim: “p*=0.563 is analytically derived”
**Verdict:** reject as stated.  
The legacy implementation searched a finite grid for an optimum under fixed hand-chosen sigmoid thresholds and slope. The numerical optimum is conditional on those arbitrary settings and is not a biological constant.

### Claim: “more intelligent bees should be worse at metacognition, r=-0.658”
**Verdict:** retire.  
The sign and magnitude were generated by the chosen functional forms. There is no same-individual empirical dataset establishing this relation.

### Claim: “circadian disruption reverses the correlation”
**Verdict:** retire.  
This was produced by a simulated distribution shift rather than demonstrated in bees.

### Claim: “central-complex predictive coding is the shared mechanism”
**Verdict:** exploratory only.  
The current behavioral evidence does not identify that neural mechanism. Perry & Barron specifically discuss mushroom-body associative circuitry as a plausible locus for uncertainty-related computation.

### Claim: “tool use supports the four-domain model”
**Verdict:** retire.  
The cited 2024 Nature result concerns social acquisition of a two-step puzzle-box behavior and should not be relabeled as direct tool-use evidence.

## New falsification standard

A mechanism earns confirmatory status only if:
1. it predicts held-out empirical data better than simpler alternatives;
2. its key parameters are identified from data rather than fixed to manufacture the target pattern;
3. the evidence is same-individual when the claim concerns individual covariance;
4. sensitivity analyses do not reverse the substantive inference;
5. the result survives an adversarial review that has access to the model code and exclusion rules.
