# ARIS4C013 · Research context

## Project

**Born to Die? A Falsification-First Test of Birth–Death Temporal Coupling Across Biological, Psychological, Cultural, and Astrological Time Systems**

## Compact scope

A preregistration-first study testing whether birth timing predicts death timing or mortality beyond ordinary seasonality, early-life environment, birthday effects and cultural calendars, with traditional Chinese calendrical/Bazi features evaluated only as prespecified incremental predictors against matched pseudo-calendar controls and independent holdouts.

epidemiology / demography / survival analysis / cultural psychology / chronobiology / metascience
