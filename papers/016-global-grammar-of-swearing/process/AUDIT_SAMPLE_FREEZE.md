## Manifest lock

The deterministic public manifest has columns:

`sample,row_index,row_hash,stratum`

and contains no taboo lexical string or translation.

When generated by the frozen sampler against the frozen source file, the
manifest SHA-256 is:

`48c58f91901e8c2a1aab01958e95ea28afaf0f33e7a98677f98e58b8a412c9b4`

This checksum is the canonical sample identity. A reviewer can regenerate the
manifest locally and verify the hash before coding.

## Anti-cherry-picking rule

After this freeze:
- rows must not be swapped because they are difficult, offensive, ambiguous,
  or inconvenient;
- coder disagreement is evidence about the measurement system, not a reason to
  remove an item;
- exclusions are allowed only under a prespecified technical rule (e.g. corrupt
  source row) and must be logged;
- replacement/backfill, if ever necessary, must use the same deterministic
  sampler and receive a new manifest version/hash.

## Privacy / public artifact rule

The public repository should retain row hashes and provenance rather than
turning the audit manifest into a browsable swear/slur list.

Coder-facing private sheets may join the frozen row indices back to the public
OSF source and should preserve the original expression, language, translation
and source labels needed for scientific review.
