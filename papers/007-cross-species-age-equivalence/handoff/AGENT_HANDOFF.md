# ARIS4C007 · Agent takeover brief

## What this project is

**Are Animal Years Comparable? Benchmarking Cross-Species Biological Age Equivalence Across Mammals**

A multi-axis benchmark of cross-species age equivalence. Life-history, independent demographic and 945 held-out homologous-event tests are complete; event-rich leave-one-Timepoint-out translation is substantially more accurate overall but remains species- and stage-dependent. Pilot 3 adds molecular/epigenetic age as an independent measurement family.
