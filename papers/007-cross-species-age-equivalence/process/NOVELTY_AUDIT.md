# ARIS4C007 · Novelty audit

Last updated: 2026-09-18

## Verdict

**PROVISIONAL GO, with a narrowed claim.**

007 should **not** claim:
- first animal-to-human age converter;
- first cross-species biological time model;
- first multi-metric age alignment;
- first pan-mammalian age estimator.

Those spaces already contain substantial work.

## Closest collision found

The strongest immediate collision is the 2026 human-cat Translating Time paper, which uses thousands of observations from brain structure, blood chemistry, bone/anatomy and behavioral milestones to align cat and human ages across the lifespan.

Therefore the publishable gap is not "combine several indicators to map cat years to human years."

## Surviving gap

The strongest current gap is a **benchmark-of-definitions** paper.

Existing literatures commonly choose one operational age coordinate and proceed:
- developmental event scale;
- maximum-lifespan fraction;
- gestation/maturity log-linear transform;
- a methylation-derived translator;
- survival/mortality curves.

ARIS4C007 instead asks whether these constructs agree when applied to the same biological question.

## Novel contributions to protect

### N1 — construct benchmark
Put distinct definitions on one common test bed rather than declaring one definition biologically meaningful in advance.

### N2 — disagreement as an outcome
Treat disagreement among age mappings as scientifically informative and model its life-stage/species determinants.

### N3 — independent held-out validation
Judge mappings with homologous events/axes not used to build the mapping.

### N4 — cycle consistency
Test whether pairwise mappings behave like projections from a shared latent coordinate.

### N5 — uncertainty-aware output
Represent an equivalent age as a distribution/multi-axis vector rather than an unsupported single number.

### N6 — phylogenetic generalization
Use leave-one-order-out and phylogenetic models so breadth of species is not mistaken for independent replication.

## Claims to avoid

Even if results are strong:
- "true biological age";
- "universal biological clock" unless strictly referring to a named published model;
- "animals age X times faster";
- "method A is the correct conversion" based only on internal prediction accuracy.

## Manuscript framing candidate

> Cross-species age translation is routinely operationalized by developmental milestones, lifespan normalization, demographic position, or molecular clocks. We benchmark these constructs as competing measurements of equivalence rather than assuming that they are interchangeable.

## Fallback novelty

If full multi-axis overlap is too sparse:
1. restrict to 10–30 data-rich mammals;
2. retain methodological depth;
3. benchmark three axes (event, demographic, methylation) rigorously;
4. use broad life-history data only for external generalization.

A smaller high-quality benchmark is preferable to a nominally pan-mammalian paper built from incompatible proxies.
