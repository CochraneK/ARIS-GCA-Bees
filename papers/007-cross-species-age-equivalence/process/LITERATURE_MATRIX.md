# ARIS4C007 · Literature and method matrix

Last updated: 2026-09-19

This is a working closest-prior-work matrix. It is designed to distinguish **age estimation within a species** from **age equivalence across species**.

| Work | Scope | Age construct | Cross-species translation? | Key contribution | Relevance to 007 |
|---|---|---|---|---|---|
| Donaldson, 1922, *The Equivalence of Age in Animals* | several animals | growth-cycle / physiological age | yes | early formal attempt to define equivalent physiological ages using growth cycles | historical prior; shows the question is >100 years old |
| Clancy et al., 2001; Workman et al., 2013 | 9 then 18 mammals | neurodevelopmental event timing | yes | regression/event model for homologous developmental sequences; Workman used 271 events | establishes event-based translation |
| Charvet et al., 2023, *PNAS Nexus* | human + 8 nonhuman primates | behavior/anatomy/transcription event scale | yes | 573 time points spanning much of lifespan | closest lifespan-scale event tradition |

## Provisional novelty boundary

The literature clearly contains:
- cross-species developmental translation;
- whole-lifespan event-scale translation for selected clades/species;
- dual-species molecular age clocks;
- pan-mammalian universal clocks;
- comparative mortality/senescence analysis.

The current search has **not yet identified** a paper whose primary design is:

1. define multiple mechanistically distinct cross-species age-equivalence mappings;
2. apply them on a common broad mammalian benchmark;
3. quantify where mappings agree/disagree across life stages;
4. evaluate them against held-out homologous events and independent axes;
5. test structural properties such as cycle consistency;
6. model disagreement using phylogeny/life-history traits.

That six-part conjunction is the working novelty claim and must be re-audited before manuscript submission.
