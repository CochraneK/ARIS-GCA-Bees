## Important newly surfaced adjacent work

### Kemp (2026) · Symmetry in category systems across languages

*Nature Communications* 17, 358.  
DOI: `10.1038/s41467-025-67463-4`

This paper is materially relevant and is now cited in Draft v1.

It models several **specific semantic category domains** using linear, bisected-linear, bisected-circular, and binary-feature structures. Bisected circular structures are used for domains including seasons, moon phases, and cardinal directions, and the theory predicts parity patterns in category-system sizes.

### Collision assessment

**Not a fatal collision.**

Kemp (2026) tests whether domain-grounded symmetry structures predict category-system parity across languages. Paper 002 tests whether a **single global circle over heterogeneous structural typological features** predicts held-out feature-association geometry better than non-periodic alternatives.

The distinction is substantive:

| Dimension | Kemp 2026 | Paper 002 |
|---|---|---|
| Unit organized | categories within a semantic domain | heterogeneous typological features |
| Geometry | domain-specified structures, including bisected circles | one learned global feature circle |
| Main prediction | parity of category-system sizes | held-out feature-association matrix |
| Comparison target | symmetry prediction by domain | circle vs tree / low-rank / graph / Euclidean / null |
| Validation | cross-linguistic domain datasets, phylogenetic controls where applicable | family hold-out, geography blocks, direct closure diagnostics, GBI/WALS replications |
| Scientific level | local/domain-specific circularity can be meaningful | global circularity of structural feature space is not supported |

This paper actually strengthens the need for Paper 002's bounded wording: **negative evidence for one global circle is compatible with genuine circular organization in specific semantic domains.**
