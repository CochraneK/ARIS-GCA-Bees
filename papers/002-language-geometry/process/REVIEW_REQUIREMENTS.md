# Secondary-review requirements carried into Paper 002

These requirements were imposed by the independent WorkBuddy / Tencent Hy3 review and are mandatory for manuscript preparation, but they did not block promotion.

1. Bootstrap intervals must be described as split-sensitivity summaries, not phylogenetic uncertainty.
2. Residual genealogical/contact dependence must remain explicit.
3. Stage 1–1I must be described as exploratory/screening, with multiplicity discussed.
4. The WALS vs TLI/GBI geographic-transfer contradiction must be preserved.
5. Claims must target the simple global-circle operationalization, not all possible linguistic periodicity.
6. Per-stage N, feature sets, feature-selection rules, effect sizes and uncertainty must be reported.

Optional improvements:
- 50–100 family-held-out splits;
- phylogenetic sensitivity analysis;
- closure-ratio annotation;
- permutation/p-value supplement.
