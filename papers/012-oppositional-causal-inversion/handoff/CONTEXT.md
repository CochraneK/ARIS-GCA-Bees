# ARIS4C012 · Research context

## Project

**When Opposites Become Causes: An Indexed Cross-Domain Framework for Oppositional Causal Inversion**

## Compact scope

ARIS4C012 studies a restricted class of apparent causal paradoxes in which increasing an exposure/intervention produces a **prespecified functional opposite** after explicit indices are restored.

Canonical representation:

`X[a,l,t,d,e] -> mechanism/feedback -> O(X)[a',l',t',d',e']`

The project explicitly rejects the literal claim that Orwellian slogans such as “war is peace,” “freedom is slavery,” or “ignorance is strength” are scientifically true.

## Why v1 needs revision

The original eight-category scheme mixed:
- index dimensions (actor / level / time / construct);
- mechanisms (feedback / overload / filtering);
- relational/power structure.

Coder A also used many free-text labels while Coder B used more standardized tokens. This made several nominal reliability fields artificially low in addition to genuine conceptual disagreements.
