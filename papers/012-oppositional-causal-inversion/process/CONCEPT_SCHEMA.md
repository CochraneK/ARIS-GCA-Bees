# CONCEPT SCHEMA — ARIS4C012

## 1. Purpose

This file defines the minimum semantics required before a candidate "opposite causes opposite" finding can enter the evidence map.

## 2. Indexed construct

Represent a construct as:

`X[a, l, t, d, e]`

where:

- `a` = actor or beneficiary;
- `l` = level of analysis (individual, dyad, group, organization, state, system);
- `t` = time horizon;
- `d` = operational definition / dimension;
- `e` = environment or regime.

A slogan that omits these indices may falsely appear self-contradictory.

## 3. Functional opposite

Define `O(X)` before testing the focal causal relation.

An admissible opposition must be justified by at least one of:

1. validated bipolar scale or established construct pair;
2. formal complement in the outcome definition;
3. domain theory specifying incompatible functional states;
4. independent expert/coder agreement.

Simple lexical antonymy is insufficient.

Examples:
- external war vs internal peace is **not** a same-variable antonym; it is a level/construct switch.
- more formal options vs lower effective autonomy is a construct switch.
- more public information vs lower social welfare is an outcome inversion, not "information = ignorance."

## 4. Candidate OCI condition

A study contributes to the OCI evidence base when the target claim can be represented as:

`do(X_i ↑) -> M -> O(X)_j ↑`

or equivalently when increasing X causes a decrease in the indexed substantive version of X:

`do(X_i ↑) -> X_j ↓`

with `i != j` on at least one declared index.

The causal contrast must be more than temporal ordering or raw association.

## 5. Same-index contradiction check

If:

`i = j`

and the claim reduces to:

`X_i ↑ -> X_i ↓`

the coder must determine whether this is:

- a legitimate dynamic/nonlinear feedback relation;
- a measurement inconsistency;
- regression to the mean / mathematical coupling;
- semantic relabelling;
- or an incoherent claim.

Literal simultaneous identity `X_i = not-X_i` is excluded.

## 6. Mechanism taxonomy

### A. Actor-switch
A's X causes B's opposite state.

### B. Level-switch
X at one aggregation level changes the opposite outcome at another.

### C. Temporal reversal
Initial effect and long-run effect have opposite signs.

### D. Construct substitution
Nominal/formal/option-based X diverges from effective/substantive X.

### E. Strategic/equilibrium feedback
Multiple agents respond to X; equilibrium feedback reverses the local effect.

### F. Capacity/overload nonlinearity
The marginal effect of X changes sign after a threshold or as signal-to-noise deteriorates.

### G. Selection/filtering
Discarding inputs improves performance because ignored information is noisy, redundant, manipulable, or costly to process.

### H. Power-asymmetry
Reducing information, autonomy, or capacity for one actor increases another actor's relative control.

## 7. Evidence strength

Code each candidate:

- E0 — rhetorical/example only;
- E1 — cross-sectional association;
- E2 — longitudinal/quasi-experimental with material residual confounding;
- E3 — credible quasi-experiment / strong identification;
- E4 — randomized experiment;
- E5 — systematic review/meta-analysis of causally informative designs.

Evidence strength is separate from effect size and from normative desirability.

## 8. Boundary-condition fields

Every candidate must code:

- intervention/exposure;
- outcome;
- actor switch;
- level switch;
- time switch;
- construct switch;
- mediator;
- moderator;
- nonlinearity/threshold;
- externality/feedback;
- study design;
- causal identification strength;
- replication/synthesis status;
- counterevidence;
- normative valence;
- whether the original authors themselves claim a paradox.

## 9. Orwell triad mapping

The three slogans are seed probes, not privileged categories.

### War is peace
Potential mappings:
- external competition -> internal cooperation;
- credible military threat -> deterrence;
- security accumulation -> insecurity (reverse-direction security dilemma).

### Freedom is slavery
Potential mappings:
- option quantity -> choice burden/deference;
- flexible connectivity -> availability norm -> reduced disconnection autonomy;
- nominal delegation -> dependence.

### Ignorance is strength
Potential mappings:
- selective information use -> robustness;
- attention constraint -> efficient allocation;
- restricted information/coordination for B -> relative control for A.

Each mapping can fail independently.
