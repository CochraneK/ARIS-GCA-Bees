## Novelty implication

A defensible novelty claim is **not**:

> "Sometimes interventions backfire."

That is already established across many literatures.

The candidate contribution is instead:

> A cross-domain, machine-codeable representation of opposite-producing causal claims that (a) restores suppressed actor/level/time/construct/environment indices, (b) distinguishes true causal reversals from rhetorical paradoxes and ordinary side effects, (c) links heterogeneous traditions through a common mechanism taxonomy, and (d) tests whether this representation has predictive and coding value beyond domain labels.

## Most dangerous novelty competitors

### 1. Rebound-effect typologies
Recent rebound work already separates mechanisms, effects, economic levels, and time frames. OCI must show generalization beyond energy/resource use and avoid rediscovering a mature multilevel typology.

### 2. Paradox theory
Paradox theory already treats contradictory yet interdependent elements across levels. OCI must remain narrower: a directional causal mapping with a prespecified opposite and explicit index changes.

### 3. Boomerang / iatrogenic literatures
These already study opposite-to-intended outcomes. OCI must show that the same representation also captures equilibrium, information, autonomy, network, and cross-actor reversals not naturally framed as interventions.

### 4. Braess / security dilemma / Goodhart
These provide formal or well-developed causal mechanisms. OCI should treat them as benchmark families, not as discoveries.

## Provisional novelty gate

**PROVISIONAL PASS ONLY.**

Pass conditions:
1. no prior umbrella theory is found that already provides the same indexed cross-domain causal representation;
2. independent coders can identify functional opposites and index switches reliably;
3. the common representation predicts mechanism/boundary classes out of domain;
4. a broad evidence map contains enough genuine cases beyond ordinary side effects.

Fail any two of these and the project should narrow to a taxonomy/review rather than a new general theory.
