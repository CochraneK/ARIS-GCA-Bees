# PILOT 0 CODING NOTE — v0.2

Updated: 2026-09-18

Before Coder A labels were entered, the Pilot 0 table was amended to separate:

- **OCI candidacy**: whether a paper tests or formalizes a relation that can be represented in the OCI schema;
- **result support**: whether the paper supports, rejects, mixes, or is neutral regarding the proposed reversal;
- **evidence mode**: empirical, formal, review, meta-analysis, or conceptual.

Reason: null and countervailing findings are essential evidence. A paper must not be excluded merely because the hypothesized reversal is absent.

Example: the 2010 choice-overload meta-analysis reported a mean effect near zero with substantial heterogeneity, whereas the 2015 meta-analysis identified moderators under which overload is more likely. Both belong in the candidate evidence family, with different `result_support` codes.

This amendment occurred before the first 30-record coding pass and therefore does not depend on Pilot 0 labels.
