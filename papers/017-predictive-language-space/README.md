# ARIS4C-017 · LING-02 · Predictive Language Space

**Conceptual successor to:** ARIS4C-002 · LING-01

ARIS4C017 asks a different question from 002.

- **002 / LING-01:** does a simple global circular / periodic geometry predict observed typological structure?
- **017 / LING-02:** can typological constraints predict held-out, missing, and genuinely unobserved language configurations?

002's negative result for a simple global circle is retained. 017 does **not** assume that language space is circular or periodic.

## Research boundary

The primary target is falsifiable prediction on observed data held out from the model. Stronger claims about extinct or unrealized languages are only allowed after the model demonstrates out-of-family predictive validity and calibrated uncertainty.
